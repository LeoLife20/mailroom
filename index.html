Mailroom — macOS

Every inbox,
one quiet room.

Mailroom is a personal macOS app that brings several Gmail accounts into one window. It reads incoming mail, surfaces verification codes so they can be copied in one click, and lets the owner mark messages as read or archive them.

Mailroom runs entirely on the owner’s own Mac. It has no servers, no accounts and no analytics. It is a private tool and is not distributed to the public.

Mailroom 是一个个人使用的 macOS 应用，把多个 Gmail 账户收进同一个窗口，用于阅读来信和快速复制验证码。它完全在本机运行，没有服务器，也不收集任何数据。
